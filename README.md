# Hotbar Locker

Lock individual hotbar slots to protect tools and items from automatic replacement when using pick block or Create Toolbox.

Assign **Toggle hotbar slot lock** in Controls, select a slot, and press the key. A gold frame, a short message, and a sound confirm the change. Locks are saved with your player.

You can still select, use, consume, and move items manually. Creative inventory clearing preserves locked hotbar stacks. If all hotbar slots are locked, Creative pick uses available main-inventory space; with no space, it leaves protected items untouched.

## Supported versions

- **Minecraft 1.20.1:** Forge, Java 17.
- **Minecraft 1.21.1:** Fabric, Forge, and NeoForge, Java 21.
- **Create Toolbox:** optional compatibility. An all-locked hotbar rejects Toolbox equip safely.
